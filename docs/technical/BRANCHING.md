# Правила веток

- Одна ветка — одна законченная функциональная задача, которую можно проверить отдельно.
- Формат: `<type>/<short-kebab-case-name>`. Типы: `feat`, `fix`, `refactor`, `docs`, `chore`.
- Имя описывает конкретное изменение: `feat/dice-match-engine`, `feat/pvp-wallet`, `feat/telegram-duel-flow`, `feat/tournament-bracket`.
- Не создавать общие ветки вроде `all_game`, `feat/all-games` или `development`, объединяющие всю реализацию игры.
- Новую задачу начинать от актуальной основной ветки (`master`). Если задача зависит от ещё не влитой ветки, явно записать зависимость в описании PR и не включать несвязанные изменения.
- Перед слиянием описать результат, границы задачи и выполненные проверки. Изменение правил игры сначала фиксировать в `docs/product/` с указанием статуса решения или предположения.
